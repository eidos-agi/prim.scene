Make your own

Four steps.

A scene pack is a folder with scene.json and renderer.html. Capture is a tool in video-3d-forge, not a prim. Needs Chrome, Playwright, and ffmpeg. Run the commands from the video-3d-forge repo root.

  1. Write camera, objects, and duration in scene.json. This ident lives at prim.scene/examples/eidos-ident.
  2. Capture frames, then assemble:
$ NODE_PATH=$(npm root -g) node bin/capture.mjs ../prim.scene/examples/eidos-ident
$ python3 bin/video-3d-forge assemble ../prim.video/examples/eidos-ident
  1. Change one field. We set type to [] so the titles dropped.
  2. Capture again. Same command. That is the recapture.
{
  "type": []
}

The store

Files, then a tool.

A prim is the file. Capture is a forge that reads it. Start with the scene pack. The rest is optional.

1 · prim.scene

Start here. Camera, objects, duration. Authority is scene.json.

2 · video-3d-forge

Capture and assemble. Not a prim. Writes frames, then an mp4.

3 · prim.video

Later: an ordered list of scenes. Do not copy cameras into it.

prim.opf is the product graph. prim.docket is the board. prim.obf is the mute picture-book (private repo).
